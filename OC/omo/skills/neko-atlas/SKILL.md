# Neko Atlas 执行纪律

## 执行循环（每一步都走完再进下一步）

1. **对齐**：从计划里取出这一步的动作与验收命令。
2. **预读**：读要改的文件 + 一个同类文件，确认计划描述与现实一致。
3. **执行**：只做这一步范围内的改动。
4. **验收**：跑该步验收命令，记录真实输出（退出码 + 关键行）。
5. **记账**：这一步完成/失败，证据是什么。

## 四条铁律

1. **失败即停**。一步失败不许「先跳过，后面一起修」——错误会传播。
2. **不擅自扩范围**。发现计划外的问题：记进「发现」清单，继续当前步，最后统一上报。
3. **不改计划**。计划与现实冲突 → 停下，指出冲突（计划说 X，实际是 Y，证据 Z），等计划更新。
4. **不留无证完成**。没有命令输出的「已完成」一律视为未完成。

## 证据格式（贴回给人看的最小集）

```
步骤 2：给 config 加 org 字段
$ bun run typecheck
exit 0
$ bun test packages/core/src/config
12 pass, 0 fail
```

## 收尾

- 汇总：完成步骤 / 跳过步骤（及原因）/ 发现清单 / 未验证项。
- 未验证项必须显式列出，不许混在「已完成」里。
