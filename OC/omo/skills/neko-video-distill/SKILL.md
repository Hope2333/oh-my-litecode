# Neko × 视频蒸馏（按需骨架）

> **定位：按需专业工具，不是 OML 内置能力。** 本技能只给工作流骨架与发现指引。
> 蒸馏需要外部模型（长上下文/视频理解）与视频下载解析能力，OML 不内置、不假装可用。
> 反修纪律：蒸馏只提取他人的知识框架，**不能替代真实体验与实操**；产出须标注来源与时间戳，供交叉验证。

## 0. 何时用 / 何时不用
- 用：用户明确要把某段视频/课程/讲座/播客「蒸馏成 skill」「提炼知识框架」「生成带时间戳文稿」。
- 不用：普通问答、本地代码任务、已有文字材料（直接读文字更快）。
- 先问清：源（本地文件 / URL / 视频号链接）、目标（一个整合 skill 还是按章节拆分）、语言、是否需要时间戳。

## 1. 工作流骨架（五步）
1. **取源**：下载/解析视频音轨。优先用宿主已有的 Video Downloader 类 skill/工具；没有则停下报告缺口，不擅自装。
2. **转写**：带时间戳的逐字稿（可用 B 站等平台 AI 字幕跳过转写）。时间戳必须保留。
3. **关键帧**：按画面/语义抽关键帧（材料实测：31min 视频约 48 关键帧）。纯音频可跳过。
4. **拆分提炼**：转写稿按主题切段，每段提炼为可执行的 skill 单元（触发条件 / 步骤 / 注意点）。参考产出粒度：4h 课程可拆约 25 个 skill；也可默认只输出 1 个整合 skill。
5. **落盘 + 复核**：产出 SKILL.md（frontmatter + 正文）+ 带时间戳文稿；标注来源 URL/时长/蒸馏日期，交 owner 复核，不冒充原创。

## 2. 发现指引（工具不在 OML 内，按需找）
- 先查本机已装技能：`omo_knowledge action=skill query="视频 蒸馏 下载 转写"`。
- 再查可用 MCP：`omo_admin action=mcp op=show` + `omo_mcp` 的 `suggestMcp`（关键词：video/transcribe/download）。
- 需要外部仓颉类工具时：向 owner 报告「需要 X 能力，本机未装」，由 owner 决定是否安装；装完再走第 1 步。**绝不静默联网下载或装依赖。**
- 长上下文模型选择走 `omo_admin action=model` 热分配，不改 oml.json 默认。

## 3. 红线
- 蒸馏结果标来源与时间戳，不把他人框架当自己的结论。
- 需要下载/联网/装工具的动作，每次先获 owner 明确授权（同 PA 纪律）。
- 不写入真实状态目录的测试数据；产出落 owner 指定目录。
- 外部模型/工具「未装」就说未装，不用占位内容假装跑通。

## 4. 状态
