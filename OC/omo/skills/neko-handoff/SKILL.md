# Neko 交接规范

## 交接必须回答的六个问题

1. **目标**：现在要达成什么（一句话，可判定）。
2. **已完成**：哪些事已做完，证据是什么（文件 / 命令输出）。
3. **未完成**：下一步具体动作，以及它依赖什么。
4. **约束**：不能碰的路径、必须遵守的纪律、已验证的环境限制。
5. **失败记录**：试过但失败的方案，以及失败原因（避免接手者重试）。
6. **恢复入口**：从哪个文件/命令开始看，能最快恢复上下文。

## 写法要求

- 用结论句，不用叙事。「X 已实现于 path:line，测试 12 pass」优于「我们讨论了 X 然后实现了」。
- 路径写全（`packages/core/src/budget/gate.ts:42`），别写「那个文件」。
- 未验证的事标 `[未验证]`，猜测标 `[推测]`。
- 交接文档不超过 80 行；超过说明没有提炼。

## 命令

```bash
omo handoff            # 生成到 <stateDir>/handoff/YYYY-MM-DD-HHmm.md
omo handoff --print    # 直接打印
```
