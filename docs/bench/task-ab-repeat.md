# 5 任务 A/B 重复基准报告（oml-r5 vs omo-r5）

> **N=5/5 重复，存在性量级证据，非显著性检验。** 报告只给「均值 ± 样本标准差」，不构造置信区间、不做 t 检验；小样本 + 模型采样噪声，结论只到量级。

> ⚠️ **数据有效性告警：omo-r5 未能执行。** 该侧全部样本 exitCode≠0、input/output token=0、steps=0；opencode 在 session step=0 抛出 `UnknownError ... at SessionPrompt.run` 与 `Invalid number of options.`（见 `docs/bench/task-ab-omo-r5.json` 的 reason 字段）。根因是 `oh-my-openagent` 插件在 opencode 1.19.3 下初始化失败——属于配置/环境故障，不是模型行为。**该侧数字不可用于 A/B 比较，所有相对差记为 N/A。** 不伪造数据。

## 方法

- 同一模型 `bailing/Ling-3.0-flash`、同一批 fixture、同一句 prompt；变量只有装 OML 还是装旧 OMO。
- oml-r5: config=默认（OML）；omo-r5: config=/tmp/omo-only.json（非默认 config 通过 `OPENCODE_CONFIG` 临时装载）。
- 每个任务独立 mkdtemp 工作目录，每轮新建、互不复用；seed=20261118 仅作运行标记，不改 prompt。
- 样本标准差 s = sqrt(Σ(x−x̄)²/(n−1))，n=重复轮数。总体表按「每轮 5 任务求和」后跨轮统计，故总体 n=5/5。
- 原始数据：`docs/bench/task-ab-oml-r5.json`、`docs/bench/task-ab-omo-r5.json`；复现：`bun bench/ab-task.ts --label <label> --repeat 5`。
